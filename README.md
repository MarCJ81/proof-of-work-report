# 작업 증빙 리포트 스튜디오

프리랜서·1인 대행사·에이전시가 클라이언트의 **“이번 달 뭐 했어요?”**에
스크린샷 더미 대신 **완료 항목 · 소요시간 · 근거 링크 · 전주 대비 변화**를 담은
공유 링크와 A4 PDF를 **1분 만에** 만드는 무서버 정적 웹앱입니다.

- 라이브(예정): `https://marcj81.github.io/proof-of-work-report/`
- 서버·DB·회원가입·결제 없음. 무료 모드에서는 입력한 내용이 브라우저 밖으로 나가지 않습니다.
- 빌드 없음. `index.html`을 열면 바로 동작합니다. 외부 CDN·폰트·스크립트 0개.
- 공유 링크는 `?d=<base64url>` 하나. 클라이언트는 로그인 없이 열고, 필요하면 A4 PDF로 저장합니다.
- 화면 톤: **A안 · Crisp Bento SaaS**(순백 타일 · 1px 보더 · 16px 라운드 · 코발트 1색).

## 1. 왜 만들었나

“이번 주에 뭐 했어요?”라는 질문에 프리랜서가 보내는 답은 대개 셋 중 하나입니다.

1. **스크린샷 8장** — 맥락이 없어서 클라이언트는 여전히 모릅니다.
2. **“열심히 했습니다”** — 다음 달 단가 협상에서 쓸 근거가 없습니다.
3. **노션 링크** — 클라이언트가 노션 계정을 만들거나, 권한 요청을 해야 합니다.

이 앱은 네 번째를 노립니다. **끝낸 일을 결과 문장으로, 걸린 시간을 숫자로, 근거를 링크로.**
클라이언트는 링크를 열어 30초 안에 읽고, 이의가 있으면 블로커의 “요청” 문장을 보고 답합니다.
프리랜서는 다음 달에 같은 리포트를 복제해 기간만 바꿉니다.

리포트의 숫자는 **입력에서만** 나옵니다. 조회수·매출·순위를 지어내지 않습니다.
AI 브리지도 “입력에 없는 숫자를 만들지 말 것”을 프롬프트 첫 규칙으로 못 박습니다.

## 2. 화면 5개

| 탭 | 하는 일 |
| --- | --- |
| **작성** | 기본 정보 + 완료/진행/다음 주/블로커 4개 그룹. 항목마다 제목·소요시간(h)·분류·근거 링크·메모·요청 |
| **클라이언트 뷰** | 받는 사람이 보는 화면 그대로. 앱 안에서 미리 확인하고 링크를 복사 |
| **이력** | 브라우저에 자동 저장된 리포트(최대 20건) 불러오기·복제·삭제, JSON 내려받기/불러오기 |
| **AI 브리지** | 거친 메모 → 클라이언트용 문장 프롬프트. ChatGPT·Claude·Gemini 새 창, Pro AI 연결 |
| **브랜드** | 로고 텍스트·회사명·담당자·연락처·브랜드 컬러·서명란. 리포트 머리말/서명에 그대로 |

### 1분 사용 순서

1. **업종 프리셋** (마케팅·블로그 대행 / 웹·앱 개발 / 디자인·브랜딩) 중 하나를 누릅니다.
   → 예시 리포트가 채워지고, 공유 링크까지 바로 만들 수 있습니다.
2. 프로젝트명·클라이언트·기간을 고칩니다. 기간은 직전 주(월~일)로 자동 입력됩니다.
3. 항목을 고치고, **근거 링크**를 붙입니다. GitHub PR·Figma 파일·Notion 페이지·구글 시트.
4. 오른쪽 장부에서 **완료 n건 · 총 h · 근거 n개 · 증빙률 %**와 전기간 대비를 확인합니다.
5. **공유 링크 만들기** → 복사 → 메신저에 붙입니다. 필요하면 **A4 PDF**.

## 3. 공유 링크는 어떻게 생겼나

```
https://marcj81.github.io/proof-of-work-report/?d=eyJ2IjoxLCJrIjoicHdyIi...
```

- **압축**: 사람이 읽는 JSON의 키를 걷어내고 항목을 배열로 바꿉니다
  (`{title, hours, evidence, memo, category, status, ask}` → `["제목", 5, "https://…", "메모", "content", "d", "요청"]`).
  예시 마케팅 리포트 기준 **원본 JSON 대비 25.6% 감소**(2,710바이트), 링크 3,614자.
- **인코딩**: UTF-8 → base64url(`+`→`-`, `/`→`_`, `=` 제거). 주소에 그대로 붙습니다.
- **표식**: 페이로드에 `k:"pwr"`를 넣어, 다른 앱의 base64를 리포트로 오해하지 않습니다.
- **상한**: 8,000자를 넘으면 “메신저에서 잘릴 수 있다”고 경고합니다(6,000자부터 주의).
- **읽기 뷰**: 링크를 열면 작성 화면 대신 클라이언트용 리포트만 렌더링합니다.
  로그인·저장소·서버가 전혀 필요 없습니다.

### 링크의 성격(중요)

링크를 아는 사람은 **누구나** 열람할 수 있습니다. 비밀번호가 없기 때문입니다.
그래서 작성 화면에 **개인정보 점검**이 있습니다. 요약·메모·요청에서
전화번호·이메일·주민번호·계좌 형태 숫자를 찾아 마스킹해 보여 주고, 공유 전에 지우라고 알립니다.
자동 감지는 완벽하지 않으므로 마지막 확인은 사람이 해야 합니다.

### 공유 전 점검(검증)

- 프로젝트명·기간이 비면 **공유 버튼이 링크를 만들지 않고** 해당 입력으로 포커스를 옮깁니다.
- 완료 항목 0건, 시작일 > 종료일, `ftp:` 같은 근거 주소는 오류로 막습니다.
- 클라이언트명 없음, 시간 0, 증빙률 50% 미만, 긴 요약은 **경고**로만 알립니다.
- 근거 URL은 렌더링 단계에서도 `http/https`만 통과합니다(`javascript:`·`data:` 차단).

## 4. A4 인쇄

`@media print`에서 화면 UI를 모두 숨기고 `#print-root`의 리포트만 인쇄합니다.
어느 탭에서 `Ctrl+P`를 눌러도 같은 결과가 나옵니다.

- `@page { size: A4; margin: 13mm 12mm 14mm }`
- 항목 카드 `break-inside: avoid`, 섹션 제목 `break-after: avoid` → 항목이 페이지 중간에서 잘리지 않습니다.
- `print-color-adjust: exact` → 브랜드 컬러·요약 밴드가 인쇄에서도 유지됩니다.
- 예시 리포트: **A4 2페이지**(1페이지 완료/진행, 2페이지 다음 주/블로커/서명).
- PDF는 브라우저 인쇄 기능으로 만들어지고 기기에만 저장됩니다.

## 5. AI 브리지 · Pro 연결

### 무료(내 구독 AI 원클릭 브리지)

- 작성한 리포트 전체(프로젝트·기간·항목·시간·근거 링크·메모)를 **프롬프트로 묶습니다**.
- 규칙: 숫자·기간·링크는 입력에 있는 것만, 확인되지 않은 원인 단정 금지,
  상투구 금지(“최선을 다하겠습니다” 등), 합니다체, 제목은 원문 유지, JSON만 출력.
- **프롬프트 복사** 후 ChatGPT·Claude·Gemini 새 창을 엽니다.
  ChatGPT/Claude는 `?q=`로 프롬프트를 넘기고(6,000자 이하), Gemini는 복사 후 붙여 넣습니다.
- 돌아온 JSON을 붙여 넣으면 **제목이 같은 항목의 메모만** 바꿉니다. 제목은 건드리지 않습니다.
  JSON이 아니면 확인을 거쳐 요약 칸에 넣습니다.

### Pro(선택, `engines/pro-api-connector.js`)

- 헤더의 `무료 모드 · API 연결` 배지 → OpenAI·Gemini·Claude·자체 서버 4탭 모달.
- 연결하면 **Pro AI로 다듬기**가 같은 프롬프트를 엔진(`generic`)으로 보내고,
  응답 JSON을 즉시 리포트에 반영합니다. 미연결이면 요청을 보내지 않고 모달만 엽니다.
- 키는 기본 `sessionStorage`(탭을 닫으면 사라짐). 공유 링크·이력·JSON에 절대 들어가지 않습니다.
